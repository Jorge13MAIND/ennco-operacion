# ADR 0002: golden path antes de módulos

## Decisión

La primera entrega funcional será una transacción sintética completa antes de ampliar UI, assistant o WhatsApp.

## Flujo

`empresa > supresión > mensaje dry run > respuesta > lead > alerta > portal > siguiente acción`

## Razón

Descubre temprano errores de contrato, integración, idempotencia, estados y observabilidad.
